# Original NimbusVault project proposal

The original PDF and `main (3).tex` were recovered byte-for-byte from commit `86264bd44be222dd7ba1d1fce63c16ca266925f2`, immediately before the original hyphenated proposal directory was deleted. These are genuine NimbusVault historical files, not the university sample.

A later original revision from commit `06bccdfafcecd75316a70b3e6c39018205d5fd65` is preserved under `revisions/2026-10-13/`, retaining its original filenames from `project_proposal/`. These versions are kept distinct; neither is relabelled as the final implementation report.

The Git history contains the same PDF blob under both the original proposal and prototype filenames. That duplication is an observed historical fact, preserved exactly rather than silently corrected. Recovery hashes and source paths are in `../docs/academic-recovery-manifest.json`. No external figures, bibliography or class files were found alongside these submissions; the recovered LaTeX sources contain their own report formatting/diagrams. Original PDFs are not overwritten when testing builds.
